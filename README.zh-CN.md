# 医学论文全流程生命周期控制器

中文 | [English](README.md)

这是一个面向医学论文完整生命周期的阶段门控 Skill。它统一管理数据和分析冻结、证据边界、作者决定、全文逻辑、写作框架、作者语域、去AI顺序、期刊适配和投稿准备，但不会把论文写成审计报告。



## 解决什么问题

医学论文常见的困难并不能靠反复润色解决：

- 写作开始后样本集、数据集或实验版本发生变化；
- 主分析、敏感性分析、探索性分析和阴性结果混在一起；
- 把公共数据库的方向一致写成独立验证；
- 把相关、共表达、富集或mRNA结果写成因果、功能或机制；
- 论断尚未稳定就建立大批参考文献，随后反复替换；
- 为了严谨而在各段重复限制，最终写成防御性或审计式论文；
- provenance、reconciliation、manifest、pipeline等内部工作语言进入正文；
- 科学内容未冻结就做去AI，导致科学修改和风格修改混在一起；
- DOCX检查通过，却误以为伦理、作者信息和投稿材料也已经完成。

本流程通过“先冻结上游、再完成下游”减少这些问题，并把科学状态、作者决定、文档质量和投稿状态分开报告。

## 核心设计

### 一、九个强制阶段门控

| 阶段 | 目的 | 最低交付物 |
|---|---|---|
| Gate 0 研究章程 | 明确问题、设计、贡献、证据层、权威来源和不做什么 | `RESEARCH_CHARTER.md` |
| Gate 1 来源冻结 | 统一样本、ID、数据集、实验来源、纳排标准和版本 | 来源清单和规范映射 |
| Gate 2 分析冻结 | 锁定统计单位、主分析、协变量、多重检验、敏感性分析和最终结果源 | 冻结结果表和分析分层 |
| Gate 3 证据冻结 | 规定每个数据集、实验、表、图和文献能支持什么、不能支持什么 | `EVIDENCE_CONTRACT.md`和论断—证据图 |
| Gate 4 框架与逻辑冻结 | 建立全文、章节、段落和句间逻辑 | `MANUSCRIPT_LOGIC_MAP.md` |
| Gate 5 科学稿与回归 | 只从冻结证据写作，并回查数字、标签、统计、图表和引用 | 科学内容稳定稿 |
| Gate 6 作者语域与去AI | 科学冻结后再应用作者习惯和AI文风清理 | 作者一致的清洁稿 |
| Gate 7 期刊适配 | 处理期刊范围、字数、结构、引用、清单和补充材料规则 | 目标期刊适配包 |
| Gate 8 文档与投稿验证 | 渲染检查文档，并另行确认伦理、作者、基金、声明和表单 | `FINAL_VALIDATION.md`和投稿判定 |

只有新增证据、数据纠正或实质性科学错误才重新打开最早受影响的门以及所有下游阶段。单纯格式修改不重新打开科学阶段。

### 二、三本账

不同性质的问题不能塞进一个笼统清单：

- **证据账 `EVIDENCE_CONTRACT.md`：**记录每层证据的设计、统计/生物学单位、直接结果、最高可支持论断、不能证明的内容和正文角色。
- **作者决定账 `AUTHOR_DECISIONS.md`：**记录必须由作者、临床专家、统计学家、机构或通讯作者决定的问题，AI不得擅自补全。
- **投稿准备账 `SUBMISSION_READINESS.md`：**独立管理期刊和行政要求，不与科学有效性或文档QA混为一谈。

这样可以避免把“分析完成”“论文润色完成”和“可以投稿”误认为同一个状态。

### 三、先建立逻辑，再使用连接词

逻辑检查分为四层：

1. **全文逻辑：**临床/生物学问题 → 具体缺口 → 研究设计 → 主要发现 → 有边界的解释 → 研究贡献 → 决定性下一步。
2. **章节逻辑：**每个章节回答一个明确问题，并把有效结论交给下一章节。
3. **段落逻辑：**每段只有一个主要任务，事实、推理和结论能够自然衔接。
4. **句间逻辑：**转折词和连接词只能标记真实关系，不能凭空制造对比、因果、递进或重要性。

实用检查方法是暂时删除大部分连接词。如果文章逻辑因此消失，应先修正顺序或推理，而不是继续添加“however”“therefore”“moreover”。

### 四、Clinical Investigator Voice

默认正文语域是“医学研究者向其他临床和科研同行解释研究”：说明做了什么、观察到什么、与已有研究有什么关系，以及在当前证据边界内意味着什么。

默认语言规则：

- 优先使用常见、准确的词；
- 同一组别、结局、实验、基因、蛋白、模型和分析使用固定术语；
- 一句话只承载一个主要意思；
- 能用短句说清楚时，不使用复杂语法；
- 全文结构清楚，但允许局部段落长短和重点自然变化；
- 真正重要的意外发现可以获得额外讨论空间；
- 局限集中放在真正影响解释的位置；
- 不通过故意添加错误、混乱、模糊或统计无知来伪装“人类写作”。

工作站中的 `AUTHOR_STYLE_PROFILE.md` 保存长期稳定的作者习惯。项目特定术语保留在具体项目中，不能因为一篇稿件就悄悄改变全局作者档案。

### 五、科学冻结后再去AI

去AI不是早期写作捷径，而是后期的科学内容保护性编辑。可以清理：

- 重复小结和重复免责声明；
- 每段完全相同的模板；
- 强行堆砌的连接词；
- 夸大的创新性和空泛意义；
- 为避免重复而使用的生僻同义词；
- 复杂名词堆叠和作者平时不会使用的语法；
- 进入正文的内部审计、来源协调和项目管理语言。

风格修改必须保持事实、样本量、数字、方向、效应量、不确定性、P值、单位、标签、技术标识符、引用、图表编号和结论强度不变。

本 Skill 不承诺“绕过AI检测”。目标是形成准确、自然、与作者习惯一致的科学表达。

## 常用论文框架

框架是骨架，不是自动生成段落的模板。

### Introduction

采用可调整的漏斗：疾病或生物学问题 → 现有证据不足 → 具体研究对象或方法 → 明确知识缺口 → 本研究如何回答。

### Methods

按证据层组织：研究设计 → 受试者/数据集 → 测量或实验 → 结局与定义 → 统计分析 → 质量和敏感性检查 → 伦理与数据可得性。

### Results

按证据阶梯组织：研究流程和样本 → 主要结果 → 互补证据 → 稳健性结果 → 阴性或边界结果 → 简短事实总结。

### Discussion：可调整的James五步法

1. 直接说明主要发现，不重复整段Results。
2. 与最相关的既往证据比较。
3. 说明研究贡献；证据允许时提出合理且可检验的解释。
4. 处理意外、阴性或矛盾结果以及替代解释。
5. 集中说明局限、临床/科学意义和最关键的下一步。

这是五种功能，不是强制五段。可以根据研究合并、拆分或调整顺序。

### Conclusion

简短说明主要结果、适用边界、证据层级以及最值得完成的下一步验证。

## 四类专门分支

所有论文共用生命周期，但不同设计有不同门控要求。

### 系统综述和Meta分析

增加方案、纳排标准、可复现检索、去重、筛选和裁决、全文排除理由、数据提取、偏倚评价、异质性、综合规则、PRISMA数量核对和检索更新日期。在纳入证据和偏倚评价冻结前，不提前锁定叙述性结论。

### 病例报告

增加临床时间线、鉴别诊断、干预、结局、随访、隐私脱敏、知情同意和CARE完整性。不能由一个病例推导发生率、治疗有效性或人群因果结论。

### 临床试验

增加注册、方案和SAP版本、预设结局、分配、盲法、分析人群、方案偏离、不良事件、受试者流程、招募日期、CONSORT核对和资助者角色。预设、修订、事后和探索性分析必须分开。

### 纯公共数据生信论文

增加accession、发布日期、样本元数据、供体/受试者单位、预处理和注释版本、批次结构、对比、多重检验、代码环境、数据集独立性以及公共数据与本地实验的不同角色。共表达、富集和预测网络不能写成已证实机制。

## 何时调用

适用于：

- 完整医学论文项目；
- 已经积累多个数据、分析、证据、稿件和文档版本的项目；
- 阶段门控审计和复杂论文挽救；
- 全文逻辑重建；
- 目标期刊和投稿材料协同准备；
- 需要生命周期管理的系统综述、病例报告、临床试验和公共生信论文。

不适用于：

- 单段润色；
- 单篇文献或DOI查询；
- 单独统计或组学分析；
- 普通去AI；
- 一次性Word排版；
- 只要求诊断而没有授权修改论文的任务。

生命周期控制器负责判断阶段和状态。文献检索、数据分析、论文起草、证据边界修订、审稿、引用核验、去AI、科研图和文档处理仍由当前阶段最合适的专门Skill执行，不能一次性加载所有能力。

将整个仓库目录复制到Codex Skills目录：

```text
Windows: C:\Users\<用户名>\.codex\skills\medical-manuscript-pipeline
macOS/Linux: ~/.codex/skills/medical-manuscript-pipeline
```

新建或重新加载Codex任务，使Skill目录重新发现。

示例请求：

```text
使用 $medical-manuscript-pipeline 判断这篇临床论文当前处于哪个阶段。

用阶段门控和三本账管理这篇系统综述论文。

先建立全文逻辑图，再开始写Discussion。

确认论断证据上限后，按James五步法组织Discussion。
```

## 安全与科学边界

- 原始数据不可变。
- 不虚构数据、文献、标识符、伦理信息、作者决定或投稿状态。
- 未经明确授权和充分脱敏，不上传可识别患者信息或未公开机密数据。
- 诊断不等于授权改稿。
- 相关不等于因果；mRNA不等于蛋白或功能；公共数据方向一致不自动等于外部验证。
- 文档QA通过不等于投稿就绪。
- 最终科学含义和投稿决定由人类作者负责。
